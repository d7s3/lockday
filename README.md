# Lockday · لوك داي

دفتر مهام عربي للجوال. تضيف مهامك بنفسك بالنماذج مثل أي تطبيق مهام، أو تملي كل شي بصوتك مرة وحدة ويرتّبه لك Claude. اجتماعات، عدّاد وقت، لوحات (اليوم، الأسبوع، الشهر، المصفوفة، السنة)، صورة لشاشة القفل، سلسلة أيام وسجل إنجازات، مدرّب أسبوعي، وثيمات وجهات تعدّلها بنفسك.

**جرّبه:** https://d7s3.github.io/lockday/

### مشاركة ورك سبيس مع ناس خارج مؤسستك
من قائمة Share: **أوقف «أي شخص معه الرابط»**، ثم ادعُ كل زميل **بإيميله بمستوى Editor**. مستوى Contributor يكفي فقط لمن هم داخل نفس المؤسسة؛ من خارجها يبقى مُشاهِداً. الـ Editor يقدر كمان ينشر نسخة جديدة من التطبيق، فادعُ من تثق فيه. مهامك الشخصية تبقى مخفية عنه في كل الحالات.

**مهم:** رابط الـ Artifact هو دفتر صاحبه. أي شخص يفتحه يحصل دفتراً خاصاً به محفوظاً على جهازه، وما يشوف مهام صاحب الرابط ولا يقدر يكتب فيها. المشاركة مفيدة لزملاء الفريق عشان ينضمون لـ«ورك سبيس» المشترك. ولو تبي كل واحد نسخة كاملة خاصة به، وجّهه لنسخة الويب.

### تشغيل الذكاء في نسخة الويب
1. افتح الإعدادات (زر الترس) ← تبويب **الذكاء**.
2. الصق مفتاح API من [platform.claude.com](https://platform.claude.com/). المفتاح يبقى في متصفحك ويُرسل مباشرة لـ Anthropic.
3. اختر الموديل. الافتراضي Fable 5.1 للوكيل والمدرّب، وSonnet 5.5 للإملاء السريع.

بدون مفتاح، الإملاء يتقسّم بطريقة بسيطة داخل الأداة، وكل شي ثاني يشتغل.

### المشاريع ومساراتها
قسم «مشاريعك» يمشّيك على كل مشروع بمراحله. يجي بثلاثة مسارات جاهزة مبنية على دورة حياة المشروع المعتمدة (تحديد ← تخطيط ← تنفيذ ← مراجعة ← إغلاق): **مسار عام**، و**مشروع ميداني** لبرامج المشاركين، و**مشروع تقني**. كل مرحلة تحمل مهامها، ومنها ما تُنسى عادةً: معيار النجاح من البداية، والمخاطر، والدروس المستفادة عند الإغلاق. تعرّف المسار مرة وحدة من الإعدادات ← مسارات المشاريع (كل سطر مرحلة، ومهامها بعد النقطتين)، وكل مشروع جديد ينزل بمراحله ومهامه جاهزة. البطاقة تعرض نسبة الإنجاز والمرحلة الحالية والخطوة الجاية، وكل مهمة تعرف أي مشروع ومرحلة تتبع.

والوكيل يعرفها: اسأله «وين وقفت في مشاريعي؟» أو «وش الخطوة الجاية؟» ويجاوبك من مراحلها، ويقدر ينشئ مشروعاً أو يقفل مرحلة.

### الإضافة اليدوية
الذكاء اختياري بالكامل. زر **+** موجود في مربع الإدخال، وفي ترويسة كل قسم، وفي لوحة اليوم. يفتح لك نموذجاً تعبّي فيه العنوان والجهة والحجم والأيام (أو التاريخ والوقت للاجتماع)، وتقدر تضيف أكثر من عنصر في نفس النموذج.

### المحادثة الصوتية
زر المايك في بطاقة «تكلّم مع Lockday»: تضغط وتتكلم، ويرد عليك بصوت عربي. وفيه خيار «محادثة مستمرة» يفتح المايك تلقائياً بعد كل رد. وزر مايك ثانٍ في مربع الإدخال يحوّل كلامك نصاً بدون إرسال. من الإعدادات ← الصوت تختار الصوت وتوقف الرد المنطوق.

يحتاج Safari أو Chrome حديث، وإذن المايك. على الآيفون لازم يكون فيه صوت عربي مثبّت: الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات ← العربية.

### على الآيفون
افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. فعّل الإملاء من إعدادات لوحة المفاتيح.

## نسخة Claude الكاملة
ارفع `artifact.html` في محادثة Claude Code واطلب نشره كـ Artifact بالصلاحيات: `db`, `sample` (مع الصور), `user` (profile), `room`, `downloads`. البيانات تتزامن مع حسابك، والفريق يشاركك ورك سبيس.

## التطوير
صفحة واحدة بدون أدوات بناء. `artifact.html` هو المصدر، و`index.html` نفس الصفحة مع رأس HTML للويب. الخطوط من Google Fonts (Badeen Display وBeiruti).
